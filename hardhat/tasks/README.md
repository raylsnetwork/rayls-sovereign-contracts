# Hardhat Tasks

## Overview
This directory contains all the Hardhat tasks for the Rayls Contracts system, providing comprehensive functionality for deployment, token management, cross-chain operations, privacy features, and system administration.

## Task Categories

### [Deployment](./deploy/readme.md)
Core system deployment tasks including privacy node and private hub setup.

### [Token Management](./tokens/readme.md)
Comprehensive token operations across ERC20, ERC721, ERC1155, and Enygma standards.

### [Enygma DvP Operations](./enygma-dvp/readme.md)
Zero-knowledge proof-based decentralized verification for cross-chain asset swaps.

### [Participant Management](./participants/readme.md)
System participant administration including roles, permissions, and status management.

### [Cross-Chain Communication](./communicator/readme.md)
Inter-network communication system for cross-chain operations and status tracking.

### [Deployment Proxy Registry](./deployment-proxy/readme.md)
Central registry for managing contract addresses and deployment information.

### [Batch Transfer Operations](./batch-transfer/README.md)
Efficient batch processing for multiple token transfers and message operations.

### [Endpoint Management](./endpoint/readme.md)
Resource ID validation and nonce parity verification for system integrity.

### [Utility Functions](./utils/readme.md)
System utilities including testing, debugging, and maintenance operations.

### [Performance Testing](./benchmark/readme.md)
Performance benchmarking and stress testing for system optimization.

### [End-to-End Testing](./e2e/readme.md)
Comprehensive testing workflows for complete system validation.

### [Protocol Security](./protocol-tests/readme.md)
Security testing and malicious attack simulation for protocol validation.

### [Version 2 Features](./v2/readme.md)
Next-generation features with enhanced performance, security, and privacy.

### [Additional Resources](./extra/readme.md)
Configuration files and additional resources for specialized operations.
