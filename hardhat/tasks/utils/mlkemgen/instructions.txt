First, go to this folder:

cd ./hardhat/tasks/utils/mlkemgen

Use the go build command to compile your file. You can specify the target OS and architecture using environment variables if different from your current system. For example:
For Windows:
    $ GOOS=windows GOARCH=amd64 go build -o mlkemgen.exe main.go
For Linux:
    $ GOOS=linux GOARCH=amd64 go build -o mlkemgen main.go
For macOS:
    $ GOOS=darwin GOARCH=amd64 go build -o mlkemgen main.go

Now you generated the executable file. To run in linux just use the ./mlkemgen command
